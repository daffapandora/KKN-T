# Peta dasar lokal

GeoJSON ini berasal dari [cuplikan API OpenStreetMap](https://api.openstreetmap.org/api/0.6/map?bbox=110.249,-7.248,110.308,-7.203) yang diambil 20 November 2026. Data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), tersedia dengan lisensi [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Ketentuan tersebut berlaku untuk berkas data GeoJSON di folder ini.

`lines.geojson` berisi jalan dan aliran terpilih, disederhanakan dan dipotong ke kotak cakupan. `places.geojson` berisi nama dusun, desa, dan kota terpilih. Data yang tidak relevan, metadata pribadi penyunting, dan batas administrasi tidak disertakan. Ini peta dasar orientasi, bukan survei resmi.
